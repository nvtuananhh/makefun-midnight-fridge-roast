`main.py` writes one original funny line — a roast of the fridge at midnight, when its light clicks on like a courtroom lamp — to `/output/entry.txt` and prints it.

> At 2am the fridge light clicks on like a courtroom lamp, and the leftover pizza testifies: 'Same guy, same crime, third night running.'

135 characters, one line. Standard library only, no network, deterministic.

## Run it

```sh
python3 main.py
```
